# Privacy Policy

**los-mobile-view** Android application is developed by [Goran Djermanovic] solely as a tool for accessing and interacting with the los-mobile web-based warehouse management system (myWMS).

This application does not collect, store, or transmit any personal data from the user.

## 1. Data Collection

The application:
- Does **not** collect personal information such as name, email, or location.
- Does **not** track user behavior or usage analytics.
- Does **not** store any data locally, apart from WebView cache and preferences, which are managed by the Android operating system.

## 2. Camera and Barcode Scanning

The app may use the device's camera for the sole purpose of scanning barcodes, initiated explicitly by the user. The scanned data is not stored or transmitted anywhere except to the currently loaded web form.

## 3. Network Communication

All communication occurs between the device and your organization's warehouse server (myWMS) over internal or configured IP addresses. The app does not contact third-party servers.

## 4. Permissions

The application may request the following permissions:
- **Camera access**: for barcode scanning.
- **Internet access**: for loading and interacting with the warehouse system.

These are essential for the app's functionality and are not used for any unrelated purposes.

## 5. Changes to This Policy

This policy may be updated if new features are introduced that affect privacy. Users will be informed via the GitHub repository's release notes or README.
